# توسيع أدوات SAM — نتيجة التطوير المعزول

تم بناء بوابة متعددة لخوادم MCP فوق مسودة البحث PR #40، ضمن محرك سام الحالي.
البوابة تقبل خادماً موثقاً لكل شركة، وأدوات قراءة مراجعة ذات بنية ثابتة، ثم تتيحها
للمخطط والمنفذ والمتحقق المستقل. لا يحصل مصدر أو خادم جديد على صلاحية من كلامه.

## ما أُنجز

- دعم حتى 8 اتصالات و24 أداة مراجعة لكل اتصال، مع حدود للمدة والحجم والاكتشاف.
- فصل الأدوات الجديدة حسب الشركة في التخطيط وإعادة التخطيط ومتابعة القراءة والتنفيذ.
- فحص المهمة والخطة والقفل والبيانات المحفوظة قبل أي قراءة جديدة مقيدة بالشركة.
- تحقق بإعادة قراءة فعلية؛ اختلاف المصدر أو فشل التحقق يبقى غير محسوم.
- حجب الأدوات غير المراجعة، وعدم الثقة بوصف الخادم أو تلميحاته عن الصلاحيات.
- إبقاء التوسعة معطلة افتراضياً وإغلاق اتصالاتها عند الإيقاف أو فشل تجهيزها.
- توثيق مراحل ربط البحث والملفات والمحاسبة والمستودع والشحن والمتصفح.

## نتيجة الاختبار

نجحت 13 حالة اختبار معزولة، بينها خادما MCP حقيقيان عبر HTTP محلي، شركتان
وبيانات دخول اختبارية منفصلة، تخطيط بنموذج اختباري محدد، وفحص SQL وتنفيذ وإعادة
قراءة مستقلة. لم تُنفذ أية أداة كتابة. نجحت أيضاً مجموعات الاختبار السابقة للبحث
والذاكرة وGoogle وواجهة bol. السجل والتفاصيل في scoped-mcp-expansion.md.

## ما لم يُنجز بعد

لم نربط مزود بحث أو محاسبة أو مستودع جديداً بالإنتاج. يلزم اختيار الخادم الحقيقي
وتفويضه لحساب الشركة ومراجعة أدواته واختباره حياً بعد انتهاء تجربة الثبات. وجود
إضافة في ChatGPT لا يعطي سام على Render بيانات دخولها تلقائياً.

هذه المرحلة توسع القراءة؛ الإرسال والشراء والتعديل والدفع بقيت ضمن ضوابطها الحالية.
فئة المتصفح في الإعدادات ليست متصفحاً جاهزاً؛ تشغيل متصفح معزول واختبار حمايته
ما زالا مطلوبين. كذلك لم يثبت هذا الاختبار تعاون النماذج الحية أو ثبات 24 ساعة.

لم ندمج أو ننشر، ولم نعد تشغيل Render أو نغير إعداداته أو أي خدمة مدفوعة أو قاعدة
إنتاج أو مهمة المتابعة. تبقى مراجعة تجربة الثبات شرطاً قبل النظر في التفعيل.
