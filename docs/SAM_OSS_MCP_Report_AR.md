للاختبار وPGlite، وليس نموذجاً حياً أو اختبار إعادة تشغيل إنتاج أو عزلاً بنظام تشغيل.

تم التحقق أيضاً من المصادر الأصلية لـGitHub MCP وRender MCP كمرشحين لإدارة الكود
والخدمات والمراقبة. لم يُثبّتا أو يُربطا بحساب المستخدم داخل سام؛ يلزم تفويض مستقل
لوقت التشغيل. وجود إضافتيهما في هذه الدردشة لا ينقل بيانات دخولهما إلى سام.

أو أي خدمة مدفوعة. مراقبة الأحداث والإشعارات تبقى ضمن مسوداتها السابقة، ولا يدعي
هذا العمل إضافة متابعة مستقلة أو تنفيذ مالي/خارجي تلقائي.
