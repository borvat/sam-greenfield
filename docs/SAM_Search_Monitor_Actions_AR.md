# إضافات سام: البحث والمراقبة والتنفيذ المقيد

العمل محفوظ على فرع تطوير معزول فوق PR #42؛ لم يُنشر على Render ولم تتغير تجربة
الثبات أو الخدمات المدفوعة أو صلاحيات الإنتاج.

ما ثبت فعلياً:

- خادم بحث مفتوح المصدر duckduckgo-mcp-server 0.7.0 يعمل عبر مخطط سام ومنفذه.
  رجعت ثلاث نتائج بروابط. نجح التحقق أول مرة، وبإعادة الاختبار تغيرت النتائج فأصبحت
  INCONCLUSIVE. البحث يعمل، لكن بوابة الثبات لا تزال مفتوحة.
- مراقبة مصدر Filesystem فعلي داخل مهام سام: خط أساس، قراءة غير متغيرة، ثم تغير.
  حُفظ حدث مراجعة داخلي واحد، دون تكرار. التوقيت في الاختبار مُحاكَى.
- كتابة تقرير محلي بأداة Filesystem الأصلية بعد موافقة اختبار محددة للشركة والهدف
  والبيانات. مُنعت الموافقة التابعة لهدف آخر، وثبت التحقق ومنع تكرار الكتابة.
- كُتب ملف فعلي ثم حوكيت خسارة الرد. سام منع الإعادة، وحُسمت النتيجة بقراءة من
  اتصال MCP جديد اعتماداً على سجل العمليات المحفوظ، ثم مُنعت كتابة مكررة من صف عمل جديد.
- أربع قراءات محاسبية مقيدة بالشركة عبر عميل e-Boekhouden الموجود، مع تحقق حقيقي
  من تطابق الرد. الاختبار ضد واجهة محلية ببيانات مصطنعة؛ ليس ربط الحساب التجاري.

المتبقي بوضوح:

قراءة صفحات الويب ما زالت تتعطل عند حارس DNS في بيئة الاختبار. لم تُلغَ الحماية.
المتصفح ما زال معطلاً بسبب غياب Chrome وفشل تنزيل Chromium وعدم السماح بإنشاء
عزل مستخدم في هذه البيئة. لم نرفق جلسة المستخدم ولم نلغِ sandbox.

المراقبة تُنتج أحداثاً وسجل مراجعة داخلياً؛ لا يوجد في هذه المرحلة تسليم إشعار للهاتف
أو إرسال خارجي أو متابعة مستقلة مثبتة لمدة زمنية فعلية. بيانات دخول أنظمة الشغل
والمستودع والشحن وربط حساباتها لم تُضف. الواجهات المصطنعة ليست اتصالاً بحساب الشركة.

الإضافات معطلة افتراضياً، وملف الكتابة مقيد بهدف محلي واحد؛ لا إرسال بريد أو شراء
أو تعديل سعر أو مخزون أو دفع أو نشر تلقائي. اختبار المخطط بنموذج محدد للاختبار،
وقاعدة PGlite معزولة؛ لا ادعاء بثبات إنتاج أو نموذج حي أو إعادة تشغيل خدمة.

تفاصيل الاختبارات والأدلة والنواقص في OSS_Search_Monitor_Actions.md وdocs/acceptance.
