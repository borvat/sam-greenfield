- اختبار احتواء مستقل:1اختبار ناجح،32طلب HTTP، صفر وصول DB. TypeScript وdiff-check نجحا عند المنفذ. فحص Gitleaks8.30.1 لنسخ15ملفاً كاملة: صفر نتائج، دون فحص التاريخ أو ادعاء أمن شامل.

## مرجع Nadr.ai والأفكار الثماني

أُضيفت النقاط الثماني التي حددها المالك إلى التكليف؛ هذه متطلبات وظيفية وليست أمراً بنسخ تقنية أو تركيب خدمات. أمكن قراءة بوابة Nadr.ai العامة عبر البحث؛ دليل AI Company HQ المحدد لم يتوفر رابطه أو محتواه في النتائج، والطلب المباشر أعاد403. لم نفترض قراءة الدليل أو تساوي التنفيذ مع SAM، ولا يُعطل ذلك اعتماد متطلبات المالك الواضحة.

## بوابة المرحلة الأولى الجاهزة للمراجعة

الإجراء المقترح محدود بالإصلاح الموجود والمنشور في [PR86](https://github.com/borvat/sam-greenfield/pull/86)، وليس مسودات الـ15 موظفاً:

2. تطبيق `00106_read_review_revisions.sql` فقط عند الحاجة، بالمشغل الموجود وبـhash `b8a62b8b5de73dea82210965132523d27adfa3cf3d3ccc84bd9fa86f70826db2`. استخدام السكربت المراجع يفحص الدور والقاعدة والـhash وACL/RLS ولا يمنح DDL لدور التطبيق.
3. نشر الخدمات القائمة فقط على exact application commit [8a08e6163516f30f37c65313134170744330c4f4](https://github.com/borvat/sam-greenfield/commit/8a08e6163516f30f37c65313134170744330c4f4)، tree974bf2fa7eab05303fa47fbd354dc535838e25af، مع autoDeployoff وخطة رجوع pinned. لا main merge ولا موارد أو أسعار أو أسرار أو شبكة جديدة.
4. اختبار native محدود للفجوة التي لم تغطها PGlite، ثم استعادة الهدف `bc17c4ae-1163-41c9-96cc-f616d7e55e0b` من أدلته المحفوظة؛ حفظ التقرير/hash السابقين وrevision واحدة، وreplay بلا قراءة/تقرير/إشعار مكرر.
5. إثبات الاسترجاع من ChatGPT والواجهة المصادق عليها، ثم دورة هدف حقيقية متعددة التخصصات ضمن القدرات والميزانية المصرح بها؛ لا أرقام أو محاكاة بديلة عن الإثبات.

الموافقة المطلوبة هي خطوة الإنتاج أعلاه، لأن المالك منع صراحةً النشر الإنتاجي دون موافقته. لا يُفسّر التكليف العام أو موافقات تاريخية كإلغاء لهذا القيد الحالي.
