A failing planner currently aborts the runtime tick, dependent steps can run before their prerequisites, and uncertain writes can be stranded outside reconciliation. This change preserves SAM's LLM/Brain/kernel/gateway architecture while making planning attempts durable and bounded, enforcing verified step dependencies and typed result references, wiring production events, and reconciling uncertain writes without resending them.

Verification now compares independent content and checks typed evidence/goal criteria. Standard capability contracts, bounded connector calls, goal-bound approvals, restricted database admission and fixed-principal tenant provisioning strengthen the execution boundary. No external capability or business-action permission is added.
