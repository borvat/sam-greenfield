---
name: Managed AI availability
description: Distinguish an unconfigured SAM project from unavailable Replit-managed OpenAI access.
---

Missing OpenAI settings or an empty ordinary connector search does not establish
that Replit-managed OpenAI is unavailable. Investigate the official managed setup
path before asking the owner for a personal provider key.

**Why:** The owner explicitly corrected this inference and required checking
official Replit-managed provisioning on the existing subscription first.

**How to apply:** Consult current official documentation for managed AI activation
and organization controls. Treat the ordinary connector catalog, managed AI
provisioning, account eligibility, and successful inference as separate checks.
If the current agent session cannot expose the managed confirmation flow, report
that specific tool limitation and the documented Project Editor action; do not
claim the account or platform lacks the feature. Never upgrade the subscription
or enable organization-wide access automatically to unblock a project-only test.
